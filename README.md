# Banking Customer & Financial Analytics

## Project Overview

Analyzed banking customer, transaction, loan, card, and account data
to understand customer behavior and financial patterns using Python,
SQL, and Power BI.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Power BI

## Project Workflow

Raw Data
→ Data Cleaning
→ Data Validation
→ EDA
→ Feature Engineering
→ SQL Analysis
→ Power BI Dashboard
→ Business Insights
→ Recommendations

## Key Analysis

- Customer demographic analysis
- Income analysis
- Transaction analysis
- Loan analysis
- Card analysis
- Correlation analysis
- SQL-based analysis
- Power BI dashboard

## Key Insights

- UPI was the most frequently used transaction type.
- Transaction amounts showed a right-skewed distribution.
- Age and annual income showed almost no linear correlation.
- Loan amount and customer income showed a very weak relationship.
- Transaction success rates varied across transaction types.

## Dashboard

Power BI dashboard includes:

1. Executive Overview
2. Customer & Account Analytics
3. Transaction Analytics
4. Loan Analytics
5. Card Analytics

## Business Recommendations

- Strengthen digital payment services based on transaction usage.
- Investigate transaction types with relatively lower success rates.
- Identify high-value customer segments for targeted banking products.
- Use customer and financial patterns to improve product targeting.
